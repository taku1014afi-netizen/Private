# リサーチメモ — 授乳グッズ（哺乳瓶・授乳クッション・消毒グッズ）の選び方 — 2026-11-01

**目的**:
新生児期〜授乳期に必要になる「授乳グッズ」まわりを、商品カテゴリ別の切り口で整理し、初めて授乳グッズを揃える家庭が迷わず選べる記事を作るための土台を作る。

既存記事との重複チェック（docs/published-topics.md確認済み）:
- 2026-09-19 離乳食グッズ → 離乳食期（生後5〜6ヶ月以降）が対象で、授乳そのものの道具は扱っていない。
- 2026-10-28 卒乳・断乳期のマグ・コップ移行グッズ → 授乳を終える段階のグッズが対象で、授乳を始める・続ける段階の道具は扱っていない。
→ 「授乳を始める・続ける段階」の道具（哺乳瓶・授乳クッション・消毒グッズ）は未着手であり、重複なしと判断。

**対象読者との関連**:
CLAUDE.md 1章のペルソナ（0〜3歳の第一子を育てる20代後半〜30代の母親）のうち、特に新生児期〜生後数ヶ月の家庭に強く関連する。母乳・ミルク・混合のいずれになるか出産前は確定しないことが多く、「とりあえず何を揃えればいいか」という失敗しない買い物の検索意図に合致する。

**主要な発見**:
- 母乳・ミルク・混合のどの授乳方法になるかは出産後に状況が変わりやすく、産前にフルセットを揃えてしまうと使わない物が出やすい、という悩みが一般的な育児情報サイトや口コミサイトでよく挙げられている（一般的な育児知識の範囲。個別の出典URLは本リサーチでは確認未実施、確認日: 2026-11-01時点の一般的傾向として記載）。
- 哺乳瓶は「素材（ガラス/プラスチック/シリコーン等）」「乳首の形状・サイズ対応」「対応する消毒方法」で選び方が分かれるという情報が一般的に知られている。
- 授乳クッションは「授乳の姿勢をサポートする」「新生児期の抱っこ補助にも使える」という用途の広さが紹介されることが多いが、効果を保証する表現（医学的な効能効果の標榜）は避けるべき領域（薬機法・景品表示法の観点で要注意）。
- 消毒グッズは「煮沸」「電子レンジ」「薬液（つけ置き）」「専用消毒器」の方式があり、家庭のライフスタイル（時短重視か、哺乳瓶の本数か）で選び分けるという切り口が一般的。
- 消毒の必要期間・方法については、月齢や自治体・小児科の案内によって見解の幅があるため、断定的な記述は避け、確認日を明記した一般論にとどめる必要がある。

**ライターへの申し送り**:
- 切り口案: 「出産前に完璧に揃えず、母乳・ミルク・混合のどちらに転んでも対応できる最小セットから考える」逆算の発想。
- 分類案: ①哺乳瓶（素材・乳首サイズ）②授乳クッション（姿勢サポート・使用期間の目安）③消毒グッズ（方式別の特徴）④買い足しのタイミングの考え方、の4分類。
- 避けるべき表現: 「母乳育児に絶対必要」「これがないと失敗する」等の断定・優良誤認につながる表現。授乳クッションやグッズの効果を医学的に保証するような言い方（薬機法・景品表示法に抵触しうる）。
- 消毒方法の必要性・期間について、具体的な月齢の線引きを断定しない（地域・小児科・家庭によって異なるため）。
